
# Guia de Estilo — Guia Turístico do Porto

## 1. Objetivo

Este guia de estilo define as cores, a tipografia
e os principais elementos visuais utilizados no
site Guia Turístico do Porto.

O objetivo é criar um site simples, organizado,
agradável e acessível aos visitantes.

## 2. Paleta de cores

As cores escolhidas foram inspiradas na identidade
visual da cidade do Porto.

| Cor | Código | Utilização |
|-----|--------|------------|
| Azul escuro | #17324D | Cabeçalho, rodapé e títulos |
| Azul | #176087 | Menu de navegação e botões |
| Cinza claro | #F3F7FA | Fundo geral do site |
| Azul claro | #DCECF5 | Fundo das secções |
| Verde claro | #E9F4EE | Fundo dos artigos |
| Branco | #FFFFFF | Texto sobre fundo escuro e conteúdo |

## 3. Tipografia

A fonte principal utilizada no site é Arial, sendo Helvetica e sans-serif utilizadas como alternativas.

Tamanhos principais:
- Título principal: 48px
- Títulos secundários: 26px
- Texto normal: 18px

Estas fontes foram escolhidas para tornar o site
mais moderno, agradável e fácil de ler.


## 4. Elementos visuais


Menu de navegação:
- Fundo transparente.
- Ligações em formato de botões arredondados.
- Botões com fundo azul e texto branco.
- Efeito visual ao passar o rato.
- Espaçamento entre as opções.

Conteúdo:
- Fundo branco.
- Secções com fundo azul claro.
- Cantos arredondados.
- Sombras suaves nas secções.
- Espaçamentos consistentes.


## 5. Acessibilidade

As cores foram escolhidas para proporcionar
contraste adequado entre texto e fundo.

Segundo as WCAG 2.2, nível AA:
- Texto normal: contraste mínimo de 4,5:1.
- Texto grande: contraste mínimo de 3:1.

Os elementos interativos também possuem
estilos de foco visíveis.

## 6. Conclusão

Este guia permite manter a mesma identidade
visual em todas as páginas do site.

A utilização de cores consistentes, tipografia
legível e espaçamentos adequados contribui
para uma melhor experiência dos utilizadores.
