Decidimos manter o Bootstrap 5.3.8 no nosso projeto Descobre o Porto.

Embora o W3.CSS tenha apresentado melhores resultados nos testes, já tínhamos utilizado o Bootstrap na E6 para criar cartões, etiquetas, botões, avisos e grelhas responsivas.

Por esse motivo, considerámos que não fazia sentido alterar a framework nesta fase do trabalho, pois teríamos de adaptar componentes que já estavam desenvolvidos e a funcionar corretamente.

Além disso, o Bootstrap permite-nos continuar a desenvolver o website, mantendo a organização e o estilo visual que já definimos nas entregas anteriores.

Assim, optámos por manter o Bootstrap, mesmo sabendo que apresentou um maior tamanho de CSS nos testes realizados.
