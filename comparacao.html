Bootstrap, Foundation e W3.CSS

Nesta página comparamos três frameworks CSS, utilizando o mesmo cartão turístico da Ribeira do Porto.

O objetivo é observar as diferenças de apresentação e implementação, mantendo o mesmo conteúdo.

Bootstrap 5.3.8

Foundation 6.9.0

W3.CSS 6

Comparação dos resultados

Para comparar as três frameworks, utilizámos o Google Chrome e a ferramenta Network. Desativámos a cache e analisámos os valores apresentados durante o carregamento das páginas.

Critério Bootstrap Foundation W3.CSS
CSS da framework 23,4 kB 14,7 kB 6,4 kB
CSS total transferido 25,0 kB 16,3 kB 8,0 kB
Pedidos de rede 5 5 5
Dados transferidos 74,6 kB 65,7 kB 57,4 kB
Tamanho dos recursos 282 kB 181 kB 77,2 kB
Tempo de carregamento 185 ms 127 ms 87 ms

Os valores foram obtidos numa medição por framework, com a cache desativada e sem limitação de velocidade. Os cinco pedidos incluem a ligação do Live Server.

Análise dos resultados

Ao analisarmos os resultados, verificámos que o W3.CSS apresentou os valores mais baixos, tanto no tamanho dos ficheiros CSS como no tempo de carregamento.

O Foundation ficou numa posição intermédia, enquanto o Bootstrap apresentou os valores mais elevados.

Apesar disso, estes resultados não significam que o Bootstrap seja uma má escolha, uma vez que os testes foram realizados apenas com um cartão e não com um website completo.

Framework escolhida

Decidimos manter o Bootstrap 5.3.8 no nosso projeto Descobre o Porto.

Embora o W3.CSS tenha apresentado melhores resultados nos testes, já tínhamos utilizado o Bootstrap na E6 para criar cartões, etiquetas, botões, avisos e grelhas responsivas.

Por esse motivo, considerámos que não fazia sentido alterar a framework nesta fase, pois teríamos de adaptar componentes que já estavam desenvolvidos e a funcionar corretamente.
