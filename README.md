
# Descobre o Porto

## Descrição
Projeto académico desenvolvido para a unidade curricular
de Programação Web - Cliente do ISLA Gaia.

O objetivo é criar um guia turístico do Porto,
com informações sobre locais a visitar, gastronomia
e outros conteúdos úteis para turistas.

## Público-alvo
Turistas portugueses e estrangeiros interessados
em conhecer a cidade do Porto.
