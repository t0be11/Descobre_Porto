
# Descobre o Porto

## Descrição
Projeto académico desenvolvido para a unidade curricular
de Programação Web - Cliente do ISLA Gaia.

O objetivo é criar um guia turístico do Porto,
com informações sobre locais a visitar, gastronomia
e outros conteúdos úteis para turistas.

## Público-alvo
Turistas portugueses e estrangeiros interessados
em conhecer a cidade do Porto.

## Framework CSS utilizada 

Na entrega E6 foi integrada a framework Bootstrap, versão 5.3.8, através de CDN.

O Bootstrap foi utilizado para melhorar a organização e a apresentação dos conteúdos, mantendo a identidade visual do website.

Foram utilizados os seguintes componentes:

Cards: apresentação dos locais turísticos.

Badges: identificação das categorias dos locais.

Buttons: botões do formulário de contactos.

Alerts: aviso informativo no formulário.

Foi também utilizado o sistema de grelha Bootstrap nas páginas locais.html e gastronomia.html, permitindo adaptar a disposição dos conteúdos a diferentes tamanhos de ecrã.

As personalizações dos componentes encontram-se no ficheiro CSS/bootstrap-custom.css, sem alterações ao código original da framework.
